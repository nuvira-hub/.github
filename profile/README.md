## NuviraHub

**Open-source remote desktop you can host yourself.** Help someone at their PC, or reach your own computers, through a server that is yours or through the free public one.

|---|:-:|:-:|:-:|
| **Windows** 10 and 11 | ✅ | ✅ | ✅ also at the lock screen and UAC prompts |
| **Linux** (Wayland and X11) | ✅ | ✅ | ✅ |
| **macOS** 13 or later | ✅ | ✅ | ✅ |
| **Browser** (NuviraHub Pro) | ✅ also from a phone or tablet | | |

- 🔒 **End-to-end encrypted**: the server never sees the screen, the input, the clipboard or the files, not even when it relays them.
- 🐳 **Your own server**: one Docker container on one port, for a NAS, a home server or a small VPS. Listed in Unraid Community Applications and in the TrueNAS apps catalog.
- ⚡ **Direct when possible**: the two devices connect directly over IPv4 or IPv6, through the relay otherwise, and over WebSocket on networks that block UDP. Hardware video encoding.
- 🧰 **Everything a session needs**: multiple screens, clipboard with text, images and files, file manager, chat, remote audio and microphone, remote terminal, remote printing, session recording, privacy mode, several technicians in one session, switch sides.
- 🌍 Five languages: English, Italian, French, German and Spanish.
- 📜 Free software under the AGPL. **NuviraHub Pro** adds team features to your server: shared address books, accounts and roles, web console, web client, single sign-on, session log, support queue, inventory, REST API. During the Founders Programme Pro is free until the launch.
