## NuviraHub

**Open-source remote desktop you can host yourself.** Help someone at their PC, or reach your own computers, through a server that is yours or through the free public one.

| | Controls other computers | Can be controlled |
|---|:-:|:-:|
| **Windows** | ✅ | ✅ also unattended |
| **Linux** (Wayland and X11) | ✅ | ✅ |
| **macOS** 13 or later | ✅ | ✅ |

- 🔒 **End-to-end encrypted**: the server never sees the screen, the input, the clipboard or the files.
- 🐳 **Your own server**: one Docker container, one port, also on a NAS (templates for Unraid included).
- ⚡ **Direct when possible**: the two devices connect directly, through the relay otherwise.
- 🌍 Five languages: English, Italian, French, German and Spanish.
- 📜 Free software under the AGPL. **NuviraHub Pro** adds team features to the server: shared address books, accounts and roles, web console, SSO and session log.
